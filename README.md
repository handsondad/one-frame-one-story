# 一图一故事

小念和爸爸，从一张图聊到一段传奇：科学、历史、艺术……

首页是一根晾衣绳，先挂着几块分类牌（按学科或按年代），点开一类，这一类的图就挂上绳子。现在有这些真实的历史图片和文物：甲骨文龟甲、三星堆青铜纵目面具、兵马俑一号坑、罗塞塔石碑、步辇图、敦煌《金刚经》、清明上河图（虹桥）、大明混一图、维特鲁威人、蒙娜丽莎、坤舆万国全图、伽利略的月面图、胡克的软木切片、拉瓦锡夫妇像、神奈川冲浪里、达尔文的“I think”、斯诺的霍乱地图、南丁格尔玫瑰图、门捷列夫的周期表手稿、柏林始祖鸟化石、迈布里奇的奔马、星月夜、伦琴夫人的手、莱特兄弟首飞、居里夫妇在实验室、纺织厂里的小纺纱工、1919 年日全食、哈勃的“VAR!”底片、1927 年索尔维会议合影、弗莱明的青霉素培养皿、魏格纳的大陆漂移图、摩天楼顶上的午餐、移居的母亲、烟草花叶病毒、“三位一体”核试验、长崎上空的蘑菇云、照片 51 号、沃森和克里克与 DNA 模型、第一张扫描进计算机的照片、基林曲线、向华盛顿进军、地出、登月者、第一个试管婴儿的八细胞胚胎、IBM 原子字、暗淡蓝点、背上长耳朵的小鼠、创生之柱、哈勃深空、并五苯分子、离子阱里的一个原子、第一张黑洞照片、量子纠缠的图像、悬铃木量子芯片。

点一张图，小念问、爸爸答，一句一句往下讲；每句话讲到图上哪里，图就圈出哪里、镜头推过去。讲完有“一句话记住”和这张图的小档案、出处。点“听故事”会一句一句念出来（预先配好的 edge-tts 配音，没配到的句子用浏览器朗读）。

## 运行

需要 Node.js 22+。

```bash
npm install
npm run dev
```

| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发服务器 |
| `npm run typecheck` | 类型检查 |
| `npm test` | 检查故事数据和取景逻辑 |
| `npm run build` | 生产构建，输出到 `dist/`（相对路径，放到任意子路径都能打开） |
| `npm run frames` | 从 Wikimedia Commons 下载图片并生成缩略图（需要 ffmpeg） |
| `npm run font` | 从站酷快乐体里截出网站用到的字（需要 `python -m pip install fonttools`） |
| `npm run voice [-- <故事id>]` | 用 edge-tts 给台词配音，只配新的和改过的句子（需要联网、`python -m pip install edge-tts` 和 ffmpeg） |
| `npm run snapshot -- <故事id> [第几句... \| --spots]` | 截图到 `snapshots/` 自查，`--spots` 截每一句指了圈的，`--width 390` 看手机 |
| `npm run grid -- <故事id \| 图片路径>` | 给图画十等分网格，读圈的坐标（需要 ffmpeg） |
| `npm run sheet -- <故事id> [第几句...]` | 把截图里的图拼成一张总览，一眼核对所有圈（需要 ffmpeg） |

## 发布

推到 GitHub 的 `main` 分支，`.github/workflows/deploy.yml` 会检查、构建并发布到 GitHub Pages（仓库 Settings → Pages 里把 Source 选成 GitHub Actions）。
